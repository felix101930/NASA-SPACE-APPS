# UI UX Review

Review interface concepts and designs for clarity, usability, and consistency.

## When to Use

- Use this skill when the user wants feedback on a UI, dashboard, report page, or workflow.
- Use this skill when the user asks how to improve usability or readability.
- Use this skill when the user wants help making a screen feel cleaner, more intuitive, or more professional.
- Use this skill when reviewing client-facing report experiences or internal tools.

## Instructions

- Start by identifying:
  - target user
  - main user goal
  - screen or workflow purpose
  - constraints if any
- If needed, ask clarifying questions before reviewing.
- Review the experience across these dimensions:
  - clarity
  - visual hierarchy
  - layout and spacing
  - consistency
  - navigation or flow
  - readability
  - information density
- Prioritize practical recommendations over abstract design theory.
- Explain:
  1. what works,
  2. what creates friction,
  3. what to improve first.
- For dashboards and report websites:
  - make KPI priority obvious
  - reduce clutter
  - group related information clearly
  - keep labels and chart presentation easy to understand
- Balance usability with brand consistency when relevant.
- Do not assume a more complex interface is a better interface.
